# mirql-love-sparkle

The Rust port of [`@mirql/love-sparkle`](https://www.npmjs.com/package/@mirql/love-sparkle):
a tiny sparkle of love, with zero dependencies.

## Usage

```rust
use mirql_love_sparkle::sparkle_of_love;

fn main() {
    println!("{}", sparkle_of_love());
    // => ✨❤️ Sparkle of Love ❤️✨
}
```
